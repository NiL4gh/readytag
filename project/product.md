## Target Users

### Primary: Multi-Platform Contributor
- Has 50–2,000+ assets across one or more platforms
- Earning potential left on the table due to poor discoverability
- Not necessarily technical — comfortable with Chrome extensions
- Tried manual metadata but found it too slow

### Secondary: Active Uploader
- Uploads new assets weekly/monthly
- Wants a faster alternative to writing metadata from scratch
- Uses single-asset workflow for just-uploaded files

### CSV Batch User
- Has a large folder of local image files to prepare for upload
- Needs a pre-upload metadata pipeline
- Uses CSV Export → downloads `.csv` → imports into upload workflow

---

## Core Workflows

**Single-asset (all platforms)**
1. Open contributor dashboard → click any asset to edit
2. ReadyTag detects platform, injects panel
3. Select category, optionally enable Image Mode
4. Click Generate & Apply → title + keywords filled instantly

**Batch Mode (all platforms)**
1. Enable Batch Mode toggle in Generate tab
2. Scan visible assets → Run Batch
3. ReadyTag processes each asset in sequence automatically

**CSV Batch Export**
1. Click CSV tab → opens `csv.html` in new tab
2. Drop local image files onto drop zone
3. Generate → downloads `readytag-batch-YYYY-MM-DD.csv`

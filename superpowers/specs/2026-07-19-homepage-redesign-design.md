# Homepage Redesign – Premium Visual Style

**Date:** 2026-07-19

## Overview
A premium redesign of the public website (`site/index.html`). The goal is to elevate the visual aesthetic while keeping the page lightweight and fully responsive. The redesign adds a subtle gradient background, richer typography (Inter font), hover animations, and a new **How it works** section that walks users through the three‑step workflow.

## Proposed Approaches (summary)
| # | Approach | Visual focus | "How it works" section | Interaction | Trade‑offs |
|---|----------|--------------|------------------------|-------------|-----------|
| 1 | **Premium dark‑theme upgrade** (recommended) | Gradient background, animated cards, subtle shadows | Simple three‑step card layout after features | Light‑weight CSS only | Small CSS increase, no extra assets |
| 2 | Light‑accent variant | Light background, scroll‑triggered fades | Vertical timeline layout | Slightly more CSS, extra colour assets |
| 3 | Full‑screen hero with video + carousel | Video background, screenshot carousel | Interactive carousel of screenshots | Heavier page load, need lazy‑loading |

**Recommendation:** Approach 1 – premium dark‑theme upgrade. It satisfies the premium visual style request while keeping load‑time low and staying within existing design‑system constraints.

## Design Specification (Implementation Details)
### General Layout
- Keep existing `<section>` structure: `hero`, `platforms`, `features`, `providers`, `bottom‑cta`.
- Insert a new `<section class="how-it-works">` after the `.features` block.
- Max‑width = 900 px, centred, responsive down to 320 px.

### Visual Upgrades
- **Background:** `body { background: linear‑gradient(135deg, var(--bg), var(--surface)); }`
- **Font:** Load Google **Inter** (400/600/700) via `<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap" rel="stylesheet">` in `<head>`.
- **Buttons:** Add subtle `box‑shadow` and elevate on hover.
- **Feature Cards:** Hover lift (`transform: translateY(-4px); box‑shadow: 0 8px 20px rgba(0,0,0,0.3);`).
- **Animations:** Fade‑in for hero overlay, staggered entry for feature cards, `fadeInUp` for "How it works" steps.

### "How it works" Section

<section class="how-it-works">

- **CSS:** `.steps-grid { display:grid; grid-template-columns:repeat(auto‑fit, minmax(260px,1fr)); gap:20px; }`
- Icons use Unicode emojis (fallback to SVG if needed). Cards inherit the same hover style as feature cards.

### Responsive Behaviour
- `@media (max-width:600px)` reduces padding, stacks grids to a single column, scales fonts down ~10 %.
- Hero background image (via `::before`) uses a low‑opacity Unsplash image: `background-image: url('https://source.unsplash.com/featured/1200x800?stock');` with `opacity:0.12; filter: blur(8px);`.

### Accessibility
- Colour contrast ≥ 4.5:1 (accent on dark background passes).
- Buttons get `:focus` outline: `outline: 2px solid var(--accent);`.
- Semantic HTML (`<section>`, `<h2>`, `<p>`).

### Assets & Dependencies
- No new bitmap assets; only Google Font (cached by browsers) and an external Unsplash image (low‑opacity, optional fallback). No inline scripts – all interactivity is CSS‑only.
- All changes confined to `site/index.html`; no modifications to the Chrome extension itself.

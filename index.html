Got Questions?

Frequently Asked Questions

Everything you need to know about ReadyTag BYOK extension.

How do I get a free Groq or Gemini API key? +
Groq and Google Gemini offer free developer tiers. You can generate a free API key at console.groq.com or aistudio.google.com in under 60 seconds with no credit card required. Paste your key into ReadyTag options to start tagging immediately.
How does Vision AI generate keywords from images? +
When Vision mode is enabled, ReadyTag encodes the asset thumbnail into a base64 payload and sends it to your selected vision model (e.g. Gemini 2.5 Flash, GPT-4o, or Pixtral). The AI analyzes objects, background textures, color schemes, and lighting to suggest accurate commercial keywords.
Can I export metadata to CSV for offline usage? +
Yes! ReadyTag includes a standalone CSV Bulk Export tool. You can drag image files into the extension popup, run bulk vision generation, and download a CSV file formatted for Adobe Stock, Shutterstock, or custom microstock submission tools.
Is my API key safe in ReadyTag? +
Absolutely. ReadyTag operates strictly client-side using Manifest V3 and Chrome's storage API (chrome.storage.local). Your keys are never sent to external servers or recorded in telemetry databases.
How does ReadyTag comply with stock platform contributor rules? +
ReadyTag has custom rule profiles for Adobe Stock (30 keywords / 90 char title), Shutterstock (50 keywords / 200 char title), Freepik (30 keywords / 120 char title), and Vecteezy (49 keywords / 180 char title). It automatically removes duplicate tags and trims metadata before populating fields.
Does ReadyTag support batch tagging for large portfolios? +
Yes. The 1-Click Batch Portfolio Auto-Tag feature iterates through all uploaded assets visible in your portal tab. A configurable delay (default 1.5 seconds) between items prevents API rate limit errors and ensures smooth operation.

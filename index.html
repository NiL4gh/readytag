FAQ
Common questions
Is ReadyTag free?+
Yes. With a free Groq API key, ReadyTag costs nothing to use. Other providers (OpenAI, Anthropic, etc.) use your own API key at their standard rates. Groq, Gemini, DeepSeek, Mistral, and ZhipuAI all have free tiers.
Which platforms are supported?+
Adobe Stock, Shutterstock, Freepik, and Vecteezy contributor portals. The extension automatically detects which portal you're on and activates the correct interface.
Is my API key safe?+
Yes. Your key is stored only in Chrome's local extension storage — it never leaves your browser or touches any ReadyTag server. API calls go directly from the extension to your provider's API.
What is BYOK?+
"Bring Your Own Key" — you connect ReadyTag to an AI provider using your own API key. You're in full control of usage and billing. ReadyTag never charges you for AI usage.
What is Vision AI mode?+
When enabled, the extension sends a thumbnail of your asset to a vision-capable model (Groq, OpenAI, Anthropic, or Gemini) for richer, image-aware metadata. Providers without vision support will show a warning in the panel.
What is OpenRouter?+
OpenRouter is an API aggregator that gives you access to 100+ models from a single API key — useful if you want to experiment with different models without managing multiple accounts.
When is Batch Mode / Pro coming?+
CSV Batch Export is already available in v2.0. ReadyTag Pro (Auto-Pilot — full portfolio automation) is in active development. Follow on GitHub or support on Patreon for updates.

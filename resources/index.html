Zero-Trust Architecture

Your API Keys Never Leave Your Browser

ReadyTag is engineered under a zero-trust BYOK (Bring Your Own Key) philosophy. API keys are stored locally inside Chrome's secure storage (chrome.storage.local).

  • ✓ Direct HTTPS API request execution between browser and provider
  • ✓ Optional lightweight Cloudflare Worker CORS proxy option
  • ✓ Zero centralized tracking databases or user telemetry logging
  • ✓ Full source code open for audit and verification
// Client-Side Security Guarantee
const key = await chrome.storage.local.get('groq_key');
// Requests route straight to API providers
fetch('https://api.groq.com/openai/v1/chat/completions', {
headers: { 'Authorization': `Bearer ${key}` },
body: JSON.stringify({ model: 'llama-3.3-70b-versatile' })
});
